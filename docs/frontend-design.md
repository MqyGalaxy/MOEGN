# 前端视觉维护

新版页面采用圆润的粉色海报风格：沿用原有亮粉到浅粉渐变，以大字背景、错位标题、圆角相纸和角色叠层组织页面。首页 Hero 后的四个栏目由 `src/components/HomeContent.astro` 渲染；首页内容选取集中在 `src/lib/homeContent.ts`，继续使用 Astro 内容集合，不另建内容副本。

## 样式边界

`src/styles/editorial.css` 由普通页面的 Layout 引入，使用独立的 `--ui-*` 变量及 `body[data-ui-page]` 页面标识；颜色引用原有品牌变量，不另设紫灰或深玫红主题。重复属性选择器用于超过 Astro 局部样式的优先级。嵌入版使用 EmbedLayout，不应用这套页面外观。

Header、各页面内容容器和页脚共用 `--ui-page-width: 1500px` 和 `--ui-gutter`。左右内边距默认 20px，720px 以下为 14px，430px 以下为 12px。收藏首页的 Hero 保持原构图，其下章节与 Header 对齐。

以下区域应保持原有样式、响应式规则及交互：

- 首页 Hero、收藏首页 Hero。
- 评测首页的 `random-review-section` 和 `review-category-section`。
- 分类页的 `category-hero`，包括原有分类主题色及响应式布局。
- `Card.astro`、`LargeCard.astro`、列表及关联作品的评分封面卡。
- 评测详情的 `detail-hero`、完整 `share-entry-panel` 和 `share-card-export`。
- 生成器四种卡片、`data-export-stage` 内的背景、装饰、水印和二维码。

不要改写上述区域依赖的旧颜色变量、字体、`.pro-link` 等公共样式。页面外围可按统一边距调整，生成器画布尺寸和内部样式不能变化；新增海报装饰应限定到章节标题、正文、工具栏或新组件，不能覆盖评分及分享画布。小屏取消过大的错位，防止装饰造成横向溢出。

## 首页数据

- 最新评测：过滤 `disable`，按 `publishedAt` 倒序；同作品路径取最新一篇，最多六篇。
- 专题：使用现有 featured 分类，收录数量与评测档案一致；封面预览按作品去重，最多三张。
- 收藏：过滤 `disable`，优先 `featured`，再按 `acquiredAt` 倒序，最多三件。仅有一件时展示完整单件布局。
- 内容不足时按实际数量展示；无内容时显示空状态，不使用隐藏内容填充。
- 评测展示使用三列／两列／单列的 CSS 瀑布流，按源数据顺序纵向流动；卡片不跨列断开，不为下一排强制留白。
- 首页使用大标题、作品封面拼贴及少量说明文字。字带、封面、角色和章节标题有持续动效，进入视口时播放入场动画与轻量视差；支持手动暂停和系统减少动态效果设置，不改变 Hero 动画。

## 分享预览弹窗

预览位于上方，说明、缩放与下载集中在下方更宽的圆角面板。缩放只作用于 `share-preview-canvas`，`share-preview-scale` 保留缩放后的占位尺寸；`share-card-export` 及其继承样式保持原样。首次打开与窗口调整时自动适应可用宽高，手动缩放后停止自动适配，点击百分比按钮恢复适配。弹窗打开期间锁定背景滚动，下载状态通过 `aria-live` 提示。

## 验证

执行 `npm test` 检查首页筛选、排序、去重与空数据；执行 `npm run build` 检查类型和静态页面生成。

涉及视觉调整时，使用生产预览检查 375、768、1024、1440px 宽度，比较上述保留区域，并验证详情分享和四种生成器样式的 PNG 导出。远程封面加载失败时，区分网络问题与布局问题；可使用站内图片验证导出流程。
